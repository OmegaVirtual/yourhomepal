# 🏡 YourHomePal

A modern, responsive web platform designed to simplify home-related services and provide users with an intuitive and accessible digital experience.

---

## 🚀 Live Website

🔗 https://yourhomepal.uk

---

## 📌 Overview

YourHomePal is a frontend-focused web project built to showcase clean design, usability, and real-world deployment skills.

The platform is designed to present home services in a structured, user-friendly way while maintaining high performance and responsiveness across all devices.

---

## ✨ Key Features

* 📱 Fully responsive design (mobile, tablet, desktop)
* 🎨 Clean and modern user interface
* ⚡ Optimized performance and fast load times
* 🧭 Simple navigation and structured content layout
* 🌐 Live deployment with custom domain
* 🔒 Cloudflare integration for security and caching

---

## 🛠️ Tech Stack

* **HTML5** – semantic structure
* **CSS3** – layout, styling, responsiveness
* **JavaScript** – interactivity and dynamic behavior

---

## ⚙️ Deployment & Infrastructure

* 🌍 Domain managed via Namecheap
* ☁️ DNS, caching, and security handled by Cloudflare
* 🚀 Global CDN for fast content delivery
* 🔧 Performance optimizations applied for real-world usage
